# Portfolio — Pawan Gupta

Single-page personal portfolio for a Product & Business Analyst.

**Live:** https://impvn.github.io/portfolio/

## About this repo

A static site with **no build step, no dependencies and no framework**. Everything
lives in `index.html` — the CSS is inline in `<style>` and the JavaScript is
inline in `<script>`, which for a single-page site means one request instead of
three and no toolchain to keep current.

```
index.html                 markup + inline CSS + inline JS
assets/
  profile-{220,440,660}.webp   profile photo (WebP, responsive)
  profile-440.jpg              profile photo (fallback for no-WebP browsers)
  brands/
    dtu-{106,212,318}.webp     DTU logo (WebP, responsive)
    dtu-212.jpg                DTU logo (fallback)
    flipkart.svg
    swiggy.svg
Pawan_Gupta_Resume.pdf
og-preview.png             1200x630 social card
apple-touch-icon.png
favicon.svg
robots.txt
sitemap.xml
scripts/check-site.mjs     dependency-free CI checks
```

## Running locally

Any static server works:

```bash
python3 -m http.server 8000
# or
npx serve .
```

Then open http://localhost:8000. Opening `index.html` directly via `file://`
also works — there is nothing that requires an HTTP origin.

## Checks

```bash
node scripts/check-site.mjs
```

No install step. It verifies:

- tags balance and there are no duplicate `id`s
- the heading outline never skips a level, with exactly one `<h1>`
- every `<img>` has `alt`, `width` and `height`
- every local asset referenced by the page exists
- every in-page anchor matches a real `id`
- external `<script>` tags carry Subresource Integrity
- page-weight and per-image budgets

Runs automatically on pull requests and pushes to `main` via
`.github/workflows/ci.yml`.

## Conventions

These are the things that are easy to undo by accident.

**Images.** Every raster asset is sized to its *display* size and shipped as
WebP with a JPEG/PNG fallback in a `<picture>`. The profile photo renders at
220 px, so the largest variant is 660 px (3x), not the original 640 px source.
Before adding an image, check what size it actually renders at and export for
that — an oversized image is the single easiest way to regress this site.

**Headings.** Section titles are `<h2>`, items inside a section are `<h3>`, and
nested subsections go to `<h4>`. Never skip a level (no `<h4>` directly under an
`<h2>`); CI enforces this.

**Scroll reveal.** Elements with class `rv` fade in via `IntersectionObserver`.
The hiding styles are scoped to `.js .rv`, and `.js` is set by an inline script
in `<head>`, so the page is fully readable if JavaScript fails. Do not add a
bare `.rv { opacity: 0 }` rule — it would blank the page for no-JS visitors.

**Reduced motion.** Honoured in CSS *and* JS. Any new JS-driven animation needs
the same `prefers-reduced-motion` guard the availability dot and the reveal
observer use — a `setInterval` is invisible to CSS media queries.

**Colour.** `--brass` is `#7d6218` (4.99:1 on `--paper`). The previous value,
`#9a7b22`, was 3.47:1 and failed WCAG AA for the small uppercase text it is
used for. Do not lighten it without re-checking contrast.

**Charts.** Bar widths in the case-study micro-charts are proportional to the
numbers they claim (baseline 92%, +4% → 95.7%). Keep them honest — they are
labelled illustrative, but a chart that visually overstates its own headline
number undermines the point of the page.

**No third-party scripts.** Animations were previously handled by GSAP +
ScrollTrigger (~70 KB, two CDN requests); they are now ~20 lines of
`IntersectionObserver`. Please don't reintroduce a framework for a fade.

## Deployment

GitHub Pages serves the **root of `main`**, so anything merged to `main` is live
within a minute. `.nojekyll` is present so Pages skips Jekyll processing.

There is no staging environment. Preview a change by running it locally or by
downloading the `site-preview` artifact from the pull request's Checks tab.

## Updating content

- **Experience duration** — computed from a start date in `index.html`
  (`expStart`, currently 16 Sept 2024). Nothing to update by hand.
- **Footer year** — inserted by JS. Nothing to update by hand.
- **`og-preview.png`** — the only asset that must be regenerated by hand if the
  hero or title changes. Keep it at 1200x630.
